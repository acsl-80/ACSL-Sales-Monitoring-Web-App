## How to send them to me

- Upload directly in chat (Plus button > Attach). Up to 10 files per message, max 20MB each — so send them in batches, roughly one chapter per message.
- Format: PNG, full browser window, desktop width (1440px wide or wider), light theme, zoom 100%.
- Name each file exactly as listed below (e.g. `09-sell-stove-form-full.png`) so I can match it to the right chapter without guessing.
- Use demo/test data where possible. If real names, phone numbers or emails appear, tell me and I will blur those regions.
- You take plain screenshots; I add the arrows, numbers, boxes and callouts. If you already know what should be pointed out, add a short note per file (e.g. "arrow to the Pay button, box around the tracking bar").
- Mobile versions are optional — only for the sidebar and Sell Stove form if you want them.
